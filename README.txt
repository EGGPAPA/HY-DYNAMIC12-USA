HY DYNAMIC12 USA V1 - LEADER + FUNDAMENTAL

한국 DYNAMIC12의 미국판입니다.

대상:
- NASDAQ (NAS)
- NYSE (NYS)
- AMEX (AMS)

흐름:
1. KIS 미국시장 순위 API로 후보 압축
   - 거래대금
   - 시가총액
   - 거래증가
   - 신고가
2. KIS 해외주식 일봉/현재가 정밀분석
3. yfinance 재무정보 보조
4. USA TOP12
5. 실제 운용은 최대 6종목
6. 종목당 1차 40% + 2차 60%
7. +10% 목표 / ATR 손절 / 과이격 추격금지

실행:
1. 기존 한국판 .env를 이 폴더로 복사
2. install.bat
3. run.bat
4. 미국시장 스캔 > ① 후보 생성 > ② 정밀분석

주의:
- 미국판에서는 한국식 외국인/기관 수급을 그대로 쓰지 않습니다.
- 시장 자금흐름은 거래대금/거래증가/신고가 랭킹으로 대체합니다.
- yfinance 재무조회 실패 시 해당 재무점수는 중립값을 사용합니다.
- 자동주문 없음.
- 세금/수수료/환율은 별도 고려가 필요합니다.

USA V1.1 AUTO JUDGMENT
- 통합점수 0~100 기준 자동판정
- 85~100 적극매수
- 75~84.9 매수후보
- 65~74.9 관찰
- 65 미만 현금대기
- 판정 표시 예: 매수후보 (79.4점)
- 판정점수 열 추가
- 과이격이면 고득점이어도 관찰로 강등

USA V1.2 TOP12 AUTO
- 오늘 TOP12 탭에서 바로 '오늘 USA TOP12 자동 생성' 가능
- 후보생성 + 정밀분석을 한 버튼으로 연속 실행
- TOP12 결과를 data/usa_top12.json에 저장
- 앱 재실행 후에도 마지막 TOP12 자동 표시
- 필요 시 '오늘 TOP12 다시 계산'으로 새로 생성

USA V1.3 DIAGNOSTIC
- 자동 TOP12 생성 실패 시 오류를 숨기지 않고 화면에 표시
- 저장 후보수 / 저장 TOP12수 / KIS키 상태 표시
- 1차 후보 생성수와 스캔 오류수 표시
- 후보가 0개면 즉시 원인 메시지 표시
- 분석 결과가 0개면 미국주식 KIS API/거래소 코드 문제로 진단
- 부분 결과도 JSON으로 저장

USA V1.4 KIS FIX
- KIS 현재가: /uapi/overseas-price/v1/quotations/price + TR_ID HHDFS00000300
- price-detail 실전전용 의존 제거
- KIS 일봉 dailyprice를 BYMD 이동 방식으로 여러 번 조회해 120일 이상 확보
- 120일 미만/일시 오류 시 yfinance 18개월 일봉 fallback
- 현재가도 KIS 실패 시 yfinance fast_info fallback
- 정상 분석 종목만 저장하고 상위 12개만 usa_top12.json에 저장
- 실패 40건이 '저장 TOP12수 40'으로 보이던 표시 오류 수정

USA V1.5 HYBRID
- KIS: 미국시장 순위 API로 후보 40개 생성만 담당
- Yahoo Finance: 후보의 18개월 일봉/현재가/재무 정밀분석 담당
- KIS 일봉/현재가 API 실패가 TOP12 전체를 막지 않도록 데이터 경로 분리
- yfinance download + Ticker.history 이중 fallback
- 클래스주 '/' -> '-' 심볼 보정
- 재무조회 실패는 빈 재무정보로 처리하여 기술분석은 계속
- 정밀분석 0개 시 실제 종목별 오류를 화면에 표시
- 정상 분석 종목만 저장, 상위 12개만 TOP12 표시

USA V1.6 PROFIT15
- 기본 목표수익률: +10% -> +15%
- +10%: 전량매도 금지, 추세 확인
- +15%: 30~50% 분할매도, 원금 일부 회수
- +20%: 추가 25% 분할매도
- +25%: 추가 25% 분할매도
- 잔여물량: 월봉 5개월선/추세 훼손 전까지 보유
- 손절: ATR + 추세 훼손 + 점수 하락 결합
- 기본 분할진입: 1차 50% / 2차 50%
- TOP12 표에 +15%, +20%, +25% 목표가 표시


V1.7 3종목 운용
- 총 운용자금 기본값: 3,000만원
- 최대 3종목, 종목당 1,000만원
- 1차 50% / 2차 50%
- TOP12의 적극매수/매수후보 중 판정점수 상위 최대 3개를 별도 표시
- 색상: 적극매수 연한 빨강 / 매수후보 연한 노랑 / 관찰 연한 파랑 / 현금대기 회색

USA V1.8 DISPLAY FIX
- V1.7에서 전체 행 배경색 때문에 글자가 흐려지는 문제 수정
- 표는 기본 다크 테마로 복원
- 판정만 이모지 색상으로 표시: 적극매수 빨강 / 매수후보 노랑 / 관찰 파랑 / 현금대기 흰색
- 판정점수와 판정을 표 앞쪽으로 이동
- TOP12 표 높이 확대

USA V1.9 STOP3
- ATR 손절가 표시 제거
- 평균매수가 = (1차매수가 + 2차매수가) / 2
- 3% 손절가 = 평균매수가 × 0.97
- TOP12 앞쪽에 1차/2차/평균/3%손절/+15/+20/+25 목표가 배치
- ATR(%)은 변동성 분석용으로만 유지
